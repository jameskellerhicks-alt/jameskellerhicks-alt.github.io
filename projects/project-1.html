Bicycle Infrastructure Prioritization

A weighted suitability model to identify and rank corridors where bicycle infrastructure investment could deliver the most benefit.

Project summary

Goal
Prioritize corridors for bicycle improvements using a transparent, criteria-based scoring approach.
My role
Built the GIS workflow/model, prepared the map outputs, and wrote the project narrative.
Tools
ArcGIS Pro, ArcGIS Online (optional publishing), Excel (optional scoring), basic Python (optional cleanup).
Method
Selected criteria (e.g., connectivity, proximity to destinations/transit, safety/context), normalized values, applied weights, and generated a corridor priority score for mapping and ranking.
Output
Priority corridor map + a shortlist of top-ranked segments for implementation discussion.
